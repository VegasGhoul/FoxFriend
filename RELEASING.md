# Выпуск обновления

1. Исправьте код и увеличьте версии `AssemblyVersion` и `AssemblyFileVersion` в `src/AssemblyInfo.cs`, а также `DisplayVersion` установщика. Используйте обычную версию, например 2.1.1.
2. Запустите `build.ps1`, затем `tests/run.ps1`, затем `installer/build.ps1`. Проверьте подарок, перетаскивание, отправку, хвост и размеры. Для проверки установщика используйте `installer/FoxFriend.exe --self-test <новая отдельная папка>`: тест не затрагивает настоящий профиль и ярлыки.
3. Сохраните изменения в репозитории. Создайте GitHub Release с тегом `v2.1.1` на этом коммите. Сначала сохраните черновик.
4. Приложите два файла: `installer/FoxFriend.exe` и `installer/FoxFriend.exe.sha256`. Второй файл создаётся сборкой автоматически. Напишите, что изменилось и какие проверки выполнены.
5. После проверки вложений опубликуйте стабильный выпуск и отметьте его последним (Latest). Не меняйте уже опубликованный EXE — для исправлений выпускайте новую версию.

Клиент проверяет `https://api.github.com/repos/VegasGhoul/FoxFriend/releases/latest` без ключей и без передачи переписки. Черновики и предварительные версии не устанавливаются. Сравнивается числовая версия; одинаковые и более старые выпуски игнорируются. Загрузка ограничена размером, SHA-256 проверяется по `digest` GitHub либо файлу `.sha256`. Повреждённая или отменённая загрузка не запускается. После проверки запускается мастер обновления с текущей папкой установки.

Интернета нет — питомец продолжает работать; фоновая проверка молчит, ручная показывает причину. Закрытие окна загрузки отменяет её. Обновление устанавливается только по действию человека. История сообщений не сохраняется, поэтому перед установкой завершите текущий разговор.
