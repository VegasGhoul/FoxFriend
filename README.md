# FoxFriend 🧡

Маленький подарок для дорогих людей: лисичка живёт на рабочем столе Windows, слушает, отвечает и уютно устраивается рядом.

**[Скачать FoxFriend.exe](https://github.com/VegasGhoul/FoxFriend/releases/latest/download/FoxFriend.exe)** · [Сообщить об ошибке или предложить идею](https://github.com/VegasGhoul/FoxFriend/issues)

Запустите установщик, выберите папку и, при желании, ярлык. При первом запуске нажмите на подарок три раза. Лисичка появится из коробки, переместится в правый нижний угол и спросит ваше имя.

- Прозрачный фон, три позы, моргание, дыхание и движение хвостика.
- Попросите «повиляй хвостиком» — лисичка помашет им в обе стороны. Погладьте щелчком; перетаскивайте мышью; меню открывается правой кнопкой.
- Напишите «сядь», «полежи» или «спокойной ночи, ложись спать».
- «Предложи тему разговора» или кнопка ☷: выбор из трёх тем. Ответьте «вторую», названием или «выбери сама». Лисичка продолжает выбранную тему вопросами; понимает «а ты?», «напомни тему», «другие темы» и «закончим».
- В 2.1.3 название книги или фильма сохраняется в текущей беседе. Повтор темы не начинает разговор заново, вопросы не ходят по кругу. Справочника сюжетов нет: лисичка сообщает об этом прямо.
- Крестик облачка оставляет поле ответа и лисичку. Скрытие — в меню правой кнопки, возврат — через значок возле часов.
- Размер лисички и размеры переписки регулируются независимо. Отправка: Enter, стрелка или оба способа; Shift+Enter — новая строка.
- Проверка обновлений доступна в настройках и выполняется в фоне при запуске. Загрузка начинается по вашей кнопке; установщик сохраняет имя и настройки.

Общение работает без интернета: собственная база реплик, распознавание фраз, настроения и основных тем. Это ограниченный анализ по правилам, не сознание и не генеративная языковая модель. Она не умеет достоверно отвечать на любой вопрос. Переписка хранится только до закрытия программы и не отправляется на GitHub. Для обновлений приложение обращается к GitHub; дополнительные модели по умолчанию выключены.

Windows 10/11, .NET Framework 4.8. Подробности — в [руководстве](ПРОЧИТАЙ%20МЕНЯ.md). Файлы программы можно удалить через `Uninstall.exe` или настройки Windows; личный профиль сохраняется.

## Разработка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
powershell -ExecutionPolicy Bypass -File .\tests\run.ps1
powershell -ExecutionPolicy Bypass -File .\installer\build.ps1
```

Используется встроенный компилятор .NET Framework и WPF. SDK и платные сервисы не нужны. Процесс следующих выпусков описан в [RELEASING.md](RELEASING.md).
